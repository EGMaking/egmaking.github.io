Token 怎么准备

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens。
  2. Repository access 选择目标仓库；Permissions 里把 Contents 设为 Read and write。
  3. 生成后复制 github_pat_…，粘贴到上方输入框，点「保存并连接」。
  4. 上传与删除都会产生 commit；GitHub Pages 通常 1 分钟内重新发布。

Token 泄露等同于把仓库写入权限交出去。不要在公共电脑保存，用完可在 GitHub 撤销。
